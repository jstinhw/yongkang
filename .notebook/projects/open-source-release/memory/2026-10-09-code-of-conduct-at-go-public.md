`CODE_OF_CONDUCT.md` is added by [[go-public]], not by [[license-and-community]], so that
GitHub's community profile shows every item green when the repo turns public. Until then the
code of conduct is the one line in `CONTRIBUTING.md`.

## Why

[[license-and-community]] held the file back until there were contributors to need one, and
go-public wants the whole community profile green; the user chose to add it at go-public
rather than accept one grey item.

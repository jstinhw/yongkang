The user asked to "create project under a specific group" and gave no detail. The reading taken:
the entry point is **New Project…** on a group's context menu (and on a pending empty group's
menu). It opens the existing New Project sheet with the group named in it, and the project lands
at the end of that group. File > New Project… and the + menu still create a loose project. A
group picker in the sheet and **Open Project…** into a group were left out. Add them if the user
asks for them.

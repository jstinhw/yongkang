Start a new project straight inside one of your sidebar groups: right-click the group, choose
New Project…, and the project lands as that group's last member.

## What changes

- A group header's context menu starts with **New Project…**, then a divider, then Rename
  Group… and Ungroup.
- A group just named from the + menu, still empty, offers the same menu on its header and on its
  dashed "Drag a project here" row. The row's wording stays.
- Opened from a group, the sheet's title names it: "New project in Client work", with the group's
  name in the dimmer ink the sidebar draws group names in. Nothing else in the sheet changes.
- Opened from File › New Project… or the + menu, the title stays "New project" and the project
  lands loose at the end of the list, as today.
- The new project is the group's last member, indented under its header, and the group's count
  goes up by one. An empty group becomes a real one with the project in it, and its dashed row goes.
- Not yet: no group picker in the sheet, and no Open Project… into a group.

Requests across projects

What you will have

  • Type a request on one board that tags another open project, and a Product session opens under each.
  • Read the two talk in their terminals: this side asks, the other files its part on its own board and answers.
  • Approve and commit each part on its own board. No agent writes into a project it wasn't started in.
  • Any agent given another project's folder asks that project for a change instead of making it.
  • See on each side which project it is talking to.

Where it waits on you

  • cross-project-request-design: look at Allen's demo and approve it, or ask for a change.
  • Nothing else: no account, secret or DNS change.
